# 连接电脑助手

[English](en/connect-computer.md) &nbsp; **简体中文**

配对完成后，可以用雷鸟 iO 打开对话、发送任务，在镜片上查看回复。

## 1. 安装并启动

1. 在安卓手机上安装改造版雷鸟 App，并确认雷鸟 iO 已和手机连接。
2. 在 Windows 电脑上安装雷鸟 iO 连接器。打开已登录的 Codex 桌面客户端，或启动 Paseo 并确认要用的助手能在其中运行。Claude Code、OpenCode 等助手通过 Paseo 接入，具体支持范围仍在验证。
3. 打开连接器。如果它还没识别到电脑上的助手，点击「刷新状态」。

[下载改造版雷鸟 App 和 Windows 连接器](https://github.com/turbotang2333/io-voice-control/releases)　[下载 Paseo](https://github.com/getpaseo/paseo/releases)

首版 Windows 安装程序未做代码签名，系统可能显示发布者未知。请从项目发行页下载，安装前可用 PowerShell 的 `Get-FileHash -Algorithm SHA256` 计算文件校验值，并与发行页的 `SHA256SUMS.txt` 核对。

> 改造版雷鸟 App 和官方版签名不同。首次安装可能需要卸载官方版，卸载前请备份要保留的本地数据。

## 2. 选择中转方式

手机和电脑通过中转服务连接。选一种方式完成配置，再扫码配对。

### 使用作者中转

可通过[小红书私信](https://www.xiaohongshu.com/user/profile/5d483e2b00000000120086a2)或[邮件（turbotang2333@gmail.com）](mailto:turbotang2333@gmail.com)获取测试码。

在连接器中选择「使用作者中转」，点击「连接并配对」，输入测试码后点击「确认并连接」。

### 自行部署中转

1. 准备一台有公网 IPv4 或域名、可用管理员权限登录的 Linux 服务器。默认端口为 TCP 443 和 2222，需要在防火墙和云服务器安全组中放行相应端口。
2. 在连接器中选择「使用自己的服务器」，填写服务器地址，点击「生成安装命令」。
3. 登录服务器，粘贴并运行连接器生成的命令。保持连接器和服务器终端打开，等待连接器自动完成配置。安装命令含一次性身份信息，请勿分享。
4. 配置完成后，在连接器中检查连接状态。如果服务器提示安装成功，但连接器没有收到结果，可按连接器里的「手动配置包方式」继续。

公网 IPv4 的自建流程已验证到电脑连上中转并显示配对二维码。手机扫码和真实助手对话仍需用最终安装包复测。

## 3. 扫码配对并试用

1. 连接器显示电脑已连接后，点击「生成配对二维码」。
2. 在手机雷鸟 App 中打开「助手设置 → 扫码配对电脑」，扫描二维码并在手机上确认。
3. 在「助手设置」选择本次配对的 Codex 或 Paseo，点击「检查连接」。戴上眼镜，说「最近对话」试用。

电脑需要保持开机联网。二维码过期时，在连接器中点击「重新生成」。

测试中曾出现眼镜唤醒后断联。配置完成后，暂时不能在连接器页面直接切换中转方式。

## 日后如何更新

从项目发行页下载新版安装程序，先退出右下角的连接器，再在原安装位置运行新版安装程序。兼容版本可覆盖更新。如果安装程序提示运行环境或安装文件版本不兼容，原安装会保留，请按新版发行说明处理。
