# 隐私与数据处理

[English](en/privacy.md) &nbsp; **简体中文**

## 电脑助手

改造版雷鸟 App 将指令发给 Windows 上的连接器，由连接器交给你选用的 AI 助手。选用的助手和模型服务如何处理指令、文件与会话，取决于该服务及其设置。

手机配对时会核对电脑端的证书指纹。按项目的加密连接设计，手机与电脑端之间的数据由中转服务转发，中转不负责解密对话。作者试用中转的测试码核验接口会使用来源 IP 做请求频率限制。自行部署时，中转服务器由你管理。

作者试用中转的线上配置和日志留存方式尚待核验。这里描述的是代码中的连接设计。

## 手机助手

雷鸟 App 在同一部安卓手机上把指令交给 Mika，使用你在手机上配置的访问令牌。Mika 按其设置完成手机操作，并可能将任务内容或屏幕信息发送给你选用的模型服务。手机路线无需本项目的中转服务。
