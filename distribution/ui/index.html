使用自己的服务器

需要有公网 IP 或域名的 Linux 服务器，并能登录服务器、开放端口。

请开放 TCP 443 和 2222。安装程序会检查并尝试安装缺少的组件。

登录服务器后粘贴运行，保持电脑连接器和服务器窗口打开。电脑会自动连接；命令含一次性身份信息，请勿分享。

使用已有配对信息
手动配置包方式

如果服务器已提示安装完成，但电脑未收到结果，可在这里填写地址和公钥、生成配置包，然后直接点“安装完成，连接电脑”，无需重复安装。

先通过可信方式登录服务器，运行 cat /etc/ssh/ssh_host_ed25519_key.pub，将输出完整复制到下方。这个公钥用来确认服务器身份。

先运行 sudo node relay/install.mjs --check 检查；通过后运行 sudo node relay/install.mjs --install 安装。安装完成并开放端口后，回到这里。

服务器 IP 变更

只适用于同一服务器、SSH 公钥未变的情况。更新后需重新连接并在手机扫码；旧配置会保留。

当前自建连接不是同地址的 IPv4 连接，请保留现有设置并检查服务器配置。

恢复中断前的配置

更新中断，旧配置仍在。请选择要恢复的旧配置；恢复后需重新检查连接。

连接帮助
